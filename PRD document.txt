### 1.1 Deterministic Hashing Specification

To eliminate duplicate variants across divergent e-commerce listings, the system MUST compute a deterministic hash string before variant insertion. The input text MUST be normalized: lowercased, whitespace-trimmed, and non-alphanumeric characters stripped.

The variant hash is computed as:


$$\text{Variant Hash} = \text{SHA256}(\text{product\_id} \mathbin{\Vert} \text{weight\_in\_grams} \mathbin{\Vert} \text{canonical\_flavor})$$

## 2. Ingestion Pipeline & Scraper Infrastructure (Python)

### 2.1 Variant Normalization Module

* **File Path:** `src/pipeline/normalizer.py`
* **External Libraries:** `re`, `hashlib`, `typing`, `pydantic`

```python
import re
import hashlib
from pydantic import BaseModel

class NormalizedVariant(BaseModel):
    weight_grams: int
    canonical_flavor: str
    variant_hash: str

class VariantNormalizer:
    FLAVOR_CANONICAL_MAP = {
        r"rich choco.*|double rich.*|belgian choco.*|chocolate fudge|dark choco.*": "chocolate",
        r"vanilla.*|french vanilla|creamy vanilla": "vanilla",
        r"alphonso mango|mango swirl|mango": "mango",
        r"cafe mocha|coffee|espresso|cappuccino": "coffee",
        r"unflavored|raw|natural|naked": "unflavored",
        r"strawberry.*|berries": "strawberry",
        r"kulfi|kesar pista": "kesar_pista"
    }

    @staticmethod
    def parse_weight(raw_title: str) -> int:
        match = re.search(r"(\d+(?:\.\d+)?)\s*(kg|g|lbs|lb|oz)", raw_title, re.IGNORECASE)
        if not match:
            return 1000

        val, unit = float(match.group(1)), match.group(2).lower()
        if unit == 'kg': return int(val * 1000)
        elif unit == 'g': return int(val)
        elif unit in ('lb', 'lbs'): return int(val * 453.592)
        elif unit == 'oz': return int(val * 28.3495)
        return 1000

    @classmethod
    def parse_flavor(cls, raw_title: str) -> str:
        for pattern, canonical in cls.FLAVOR_CANONICAL_MAP.items():
            if re.search(pattern, raw_title, re.IGNORECASE):
                return canonical
        return "unflavored"

    @classmethod
    def execute(cls, product_id: str, raw_title: str) -> NormalizedVariant:
        weight_g = cls.parse_weight(raw_title)
        flavor = cls.parse_flavor(raw_title)
        raw_signature = f"{product_id}_{weight_g}_{flavor}".lower().strip()
        v_hash = hashlib.sha256(raw_signature.encode('utf-8')).hexdigest()
        
        return NormalizedVariant(weight_grams=weight_g, canonical_flavor=flavor, variant_hash=v_hash)

```

## 4. Scientific Analytics & Equalizer Computation Engine

### 4.1 Bioavailability Mathematical Specifications

The analytics engine standardizes all products into an absolute cost of biologically useful protein.

$$\text{Absorbed Protein (g)} = \text{Label Protein per Serving (g)} \times \text{DIAAS Multiplier}$$

$$\text{Effective Yield Cost (₹/g)} = \frac{\text{Current Lowest Price (INR)}}{\text{Total Servings} \times \text{Absorbed Protein (g)}}$$

$$\text{Flavor Tax (\%)} = \left( \frac{\text{Effective Yield Cost}_{\text{flavored}}}{\text{Effective Yield Cost}_{\text{unflavored}}} - 1 \right) \times 100$$

### 4.2 Analytical Calculator Implementation

* **File Path:** `src/analytics/equalizer.py`

```python
class EqualizerEngine:
    # Based on FAO-recommended clinical digestibility standards
    DIAAS_INDEX = {
        "whey_isolate": 1.09,
        "whey_concentrate": 0.98,
        "casein": 1.18,
        "soy": 0.90,
        "plant_blend": 0.85, # Synergistic Pea + Rice formulation
        "pea_isolate": 0.82,
        "rice_protein": 0.42
    }

    @classmethod
    def calculate_metrics(
        cls, 
        category: str, 
        price_inr: float, 
        label_protein_g: float, 
        serving_size_g: float, 
        total_servings: int,
        unflavored_cost_per_g: float = None
    ) -> dict:
        diaas = cls.DIAAS_INDEX.get(category, 0.80)
        absorbed_protein_per_serving = round(label_protein_g * diaas, 2)
        total_absorbed_protein = absorbed_protein_per_serving * total_servings
        effective_cost_per_g = round(price_inr / total_absorbed_protein, 2) if total_absorbed_protein > 0 else 0.0
        purity_pct = round((label_protein_g / serving_size_g) * 100, 2) if serving_size_g > 0 else 0.0

        flavor_tax_pct = 0.0
        if unflavored_cost_per_g and unflavored_cost_per_g > 0:
            flavor_tax_pct = round(((effective_cost_per_g / unflavored_cost_per_g) - 1.0) * 100, 2)

        return {
            "diaas_score": diaas,
            "absorbed_protein_per_serving_g": absorbed_protein_per_serving,
            "total_absorbed_protein_pool_g": total_absorbed_protein,
            "effective_cost_per_bioavailable_g_inr": effective_cost_per_g,
            "scoop_purity_pct": purity_pct,
            "flavor_tax_pct": max(flavor_tax_pct, 0.0)
        }

```

**Objective:** Evolve the platform from a price aggregator into a defensive intelligence terminal. The system MUST algorithmically detect formulation deception, bot manipulation, counterfeit risks, and extreme pricing arbitrage to protect consumer health and budgets.

### 9.1 Proprietary Blend Exposer (Fairy-Dusting Detection)

* **File Path:** `src/analytics/ingredient_auditor.py`
* **Execution Paradigm:** NLP-based sequence evaluation governed by FSSAI descending-weight mandates.
* **Algorithmic Procedure:**
1. Ingest comma-separated raw ingredient string from OCR or scraped HTML payload.
2. Normalize string (lowercase, strip brackets).
3. Map array indices of predefined `FILLERS` (maltodextrin, taurine) and premium `ACTIVES` (citrulline, whey isolate).
4. **Evaluation Rule:** If `Index(FILLER) < Index(ACTIVE)`, flag `is_fairy_dusted = True`.
5. Compute `trust_score` deduction ($-$15 points per unique violation).


* **Agent Directive:** Bind output to `products.trust_score` and expose violation strings in the Next.js Due Diligence modal.

### 9.2 Near-Expiry Clearance Arbitrage

* **File Path:** `src/analytics/expiry_arbitrage.py`
* **Execution Paradigm:** Temporal consumption forecasting vs. expiration delta.
* **Algorithmic Procedure:**
1. Parse `expiry_date` from e-pharmacy DOM (e.g., Tata 1mg, Apollo).
2. Calculate `months_to_expiry` relative to current system time.
3. Calculate `months_to_finish` = `(total_servings / user_scoops_per_day) / 30`.
4. **Evaluation Rule:** Define `is_safe_for_consumption` ONLY IF `months_to_expiry > (months_to_finish + 1.0)` (enforcing a strict 1-month safety buffer).
5. Define `is_clearance` IF discount > 25% AND `months_to_expiry` $\le$ 5.


* **Agent Directive:** Build a dedicated `/clearance` API route and Next.js frontend feed that surfaces ONLY items passing the `is_safe_for_consumption` check.

### 9.3 Review Authenticity Engine (Bot-Filtering)

* **File Path:** `src/vision/review_authenticity.py`
* **Execution Paradigm:** Lexical Jaccard Similarity and Temporal Clustering.
* **Algorithmic Procedure:**
1. Siphon the most recent 100 5-star reviews for a given SKU.
2. **Cluster Audit:** Traverse sorted timestamps. If $\ge$ 5 reviews occur within a $\le$ 24-hour delta window, increment `temporal_cluster_flags`.
3. **Lexical Audit:** Execute pairwise Jaccard similarity comparison across all 5-star texts. If overlap > 0.65 (65% identical words), increment `copy_paste_flags`.
4. **Penalty Formula:** `Authenticity Score = 100 - (clusters * 10) - (copy_pastes * 5)`.


* **Agent Directive:** Render the `Authenticity Score` as a progress bar component on the UI. If score < 60, aggressively overlay a `High Bot Risk` warning.

### 9.4 Marketplace Seller Trust Matrix

* **File Path:** `src/pipeline/seller_matrix.py`
* **Database Requirement:** Query against `seller_trust_registry` whitelist table.
* **Algorithmic Procedure:**
1. Scrape `sold_by` DOM node from third-party marketplaces (Amazon, Flipkart).
2. Normalize seller string and cross-reference against static `AUTHORIZED_DISTRIBUTORS` array (e.g., Cocoblu, SuperComNet) OR verify direct brand storefront naming.
3. **Evaluation Rule:** If match fails, mutate `price_listings.is_authorized_seller` to `False`.


* **Agent Directive:** UI MUST visually segregate unauthorized sellers. If an unauthorized seller holds the lowest price, the frontend MUST NOT use it for the primary "Lowest Price" badge; it must default to the lowest *authorized* price.

### 9.5 Independent Lab Scorecard (NABL Integration)

* **File Path:** `src/compliance/lab_auditor.py`
* **Database Requirement:** Query against `independent_lab_tests` table.
* **Algorithmic Procedure:**
1. Calculate Protein Variance: `((lab_yield - label_yield) / label_yield) * 100`.
2. Check against FSSAI maximum thresholds: Lead (Pb) $\le$ 2.5 mg/kg, Arsenic (As) $\le$ 1.1 mg/kg.
3. **Evaluation Rule:** `passed_audit = True` IF variance $\ge -5.0\%$ AND heavy metals $\le$ thresholds.


* **Agent Directive:** Display a prominent `🛡️ 3rd-Party Lab Verified` Gold Shield in the UI for passing products, and a hyperlink to the raw PDF `report_url`.

### 9.6 Glitch Price Webhook Engine (Extreme Arbitrage)

* **File Path:** `src/notifications/webhook_engine.py`
* **Integration:** Discord / Telegram Webhook API.
* **Algorithmic Procedure:**
1. On every price insertion, query PostgreSQL for the 90-day moving average of `current_price_inr` for that specific `variant_id`.
2. Calculate discount delta from the moving average.
3. **Evaluation Rule:** If delta > 30% AND `is_authorized_seller == True`, generate a Markdown-formatted alert payload.
4. Dispatch POST request to Webhook endpoint containing product name, flash price, normal price, and outbound affiliate URL.


* **Agent Directive:** Execute webhook asynchronously to prevent blocking the main ingestion pipeline thread.
