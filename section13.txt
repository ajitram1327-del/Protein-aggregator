13. Price History & Combination Tracking Engine

Objective: Track price movement for every indexed variant over time, and extend that tracking to user-defined combinations of products (a "stack" — e.g. whey + creatine + a gainer), over any designated period. This turns the platform from a spot-price snapshot tool into an actual time-series terminal — the same shape as a stock chart, but for a basket of supplements.

13.1 Time-Series Data Model

Your existing price_listings table (Section 3.2) is already append-only — every scrape inserts a new row rather than overwriting — which makes it usable as a raw tick log. But raw ticks alone don't scale to a 1-year chart efficiently, so this adds a rollup layer.

-- Table 5: Daily OHLC-Style Price Rollup (per variant, per platform)
CREATE TABLE price_history_daily (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    variant_id UUID NOT NULL REFERENCES variants(id) ON DELETE CASCADE,
    platform_name VARCHAR(50) NOT NULL,
    trade_date DATE NOT NULL,
    open_price_inr NUMERIC(10, 2) NOT NULL,
    close_price_inr NUMERIC(10, 2) NOT NULL,
    low_price_inr NUMERIC(10, 2) NOT NULL,
    high_price_inr NUMERIC(10, 2) NOT NULL,
    was_in_stock_pct NUMERIC(5, 2) NOT NULL DEFAULT 100.00,
    sample_count INTEGER NOT NULL DEFAULT 0,
    UNIQUE(variant_id, platform_name, trade_date)
);
CREATE INDEX idx_price_history_lookup ON price_history_daily(variant_id, trade_date DESC);

-- Table 6: Best-Price-Across-Platforms Daily Rollup
CREATE TABLE price_history_best_daily (
    variant_id UUID NOT NULL REFERENCES variants(id) ON DELETE CASCADE,
    trade_date DATE NOT NULL,
    lowest_authorized_price_inr NUMERIC(10, 2) NOT NULL,
    best_platform VARCHAR(50) NOT NULL,
    effective_cost_per_bioavailable_g_inr NUMERIC(10, 4),
    PRIMARY KEY (variant_id, trade_date)
);

13.2 Rollup & Retention Job
- File Path: src/jobs/price_rollup.py
- Trigger: Nightly scheduled Cloud Function.
- Algorithmic Procedure: Aggregate prior day's scrapes into OHLC metrics.

13.3 Combination ("Stack") Schema
CREATE TABLE stacks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID,
    name VARCHAR(150) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE TABLE stack_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    stack_id UUID NOT NULL REFERENCES stacks(id) ON DELETE CASCADE,
    variant_id UUID NOT NULL REFERENCES variants(id) ON DELETE CASCADE,
    quantity INTEGER NOT NULL DEFAULT 1 CHECK (quantity > 0),
    repurchase_cycle_days INTEGER NOT NULL DEFAULT 30,
    UNIQUE(stack_id, variant_id)
);
CREATE INDEX idx_stack_items_stack ON stack_items(stack_id);

13.4 Combination Price Computation Engine
- File Path: src/analytics/stack_pricer.py
- Stack Cost(t) = Sum(quantity_i * LowestAuthorizedPrice_i(t))

13.7 Personal Price & Stack Alerts
CREATE TABLE price_alerts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    target_type VARCHAR(10) NOT NULL CHECK (target_type IN ('variant', 'stack')),
    target_id UUID NOT NULL,
    threshold_price_inr NUMERIC(10, 2) NOT NULL,
    direction VARCHAR(4) NOT NULL CHECK (direction IN ('below', 'above')),
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    last_triggered_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
